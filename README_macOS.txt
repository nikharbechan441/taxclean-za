TaxClean ZA - Offline SARS Bank Statement Converter (macOS Edition)
100% Offline POPIA Compliance · Sage Pastel, Xero & QuickBooks
========================================================================

HOW TO RUN ON macOS:
1. Double-click "Run_TaxClean_ZA_Mac.command"
2. If macOS displays a security prompt on first launch:
   Right-click (or Control-click) "Run_TaxClean_ZA_Mac.command" -> Select "Open" -> Click "Open".
3. The app will start immediately on your Mac desktop.

KEY FEATURES ON macOS:
- Full support for macOS Dark Mode & Light Mode
- Native Command key shortcuts (Cmd+O to open, Cmd+P for preview, Cmd+Z for undo, Cmd+K for practice master)
- Converts messy SA bank PDFs (FNB, Capitec, Standard Bank, Nedbank, ABSA) into clean Xero & Sage CSVs
- Generates 5-tab SARS VAT201 working paper Excel files locally

DATA PRIVACY & POPIA:
All statement processing occurs 100% locally on your Mac. No bank statements or financial records are ever uploaded to any cloud server.
